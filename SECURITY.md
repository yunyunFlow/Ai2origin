# Safe reports and execution

Generated plans are drawing programs. Review them before native execution;
the drawing filter is not a sandbox for an untrusted edited plan. Configuration
and CSV text must not become arbitrary executable instructions.

Public reports must use minimal synthetic data and redacted environment
details. Do not attach complete OPJU projects, raw research results, keys,
license details or complete runtime logs to public issues.

No private reporting address or hosted advisory channel has been established
by this local package. Use a private maintainer channel only when one is
actually provided. No response time or remediation guarantee is promised.
