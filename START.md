# Start or continue a plotting task

Copy this prompt into an AI tool that can read files and run scripts. Replace
the brackets with your task. For an existing task, include its config and outputs.

```text
Use Ai2origin to plot [my files] for [my goal].
Requested output: [PNG / PNG and SVG / editable Origin project and PNG].
Existing work, if any: [config, figures and notes].

Read README.md and SKILL.md in the skill folder first. Inspect the supplied
files and existing work before changing anything. Check quantities, units,
sample identities, acquisition order and prior processing. Ask one short
question if a missing fact would change the result.

Choose or adapt a suitable plot and write the mapping/config yourself. The
examples are starting points; use other available tools when needed. Verify
any conversion against the original values and units.

Preserve originals, source order and measured points. Record any processing
or calculation, its parameters and a necessary method citation. Use installed
Arial; if missing, show local fonts and ask me to choose one. Record the actual
font. Never download or copy font files. Explain any software setup before
changing my environment.

Save outputs to a new folder outside the skill. Inspect the actual image and
check its data, labels, units, legends and clipping. For Origin, check the
saved/reopened project as well. Repeat exports only when I request it or when
diagnosing a reproducibility problem; no manual hash checks for normal use.
Reuse valid existing work and check changes. Report the output files, choices,
performed checks and anything still unresolved briefly.
```
